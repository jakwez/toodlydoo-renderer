# toodlydoo-renderer
- ongoing toy project to understand and play with 3D Math, matrices, rendering in general, etc...
- loosely based off the examples in the 3D Math section of the excellent [WebGPU Fundamentals](https://webgpufundamentals.org/) 
- ...but purely implemented in JS/TS in a 2D canvas, no use of WebGPU (for eg: vertex shader as a JS function!)
- super slow, inefficient, and ugly, not meant to be anything but educational/self-training piece of code
- might replace/complete canvas 2D with homemade software rendering, z-buffer, rasterization, etc... just for fun and learning
